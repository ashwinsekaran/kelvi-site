# kelvi.in — landing page

Static landing page for **Kelvi**, served via GitHub Pages at https://kelvi.in.

- Single self-contained `index.html` (no build step, no dependencies).
- `CNAME` binds the custom domain `kelvi.in`.
- `.nojekyll` disables Jekyll processing (serve files as-is).

To edit: change `index.html` and push to `main` — GitHub Pages redeploys automatically.
